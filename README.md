# EFX Allocation on Graphs

Υλοποίηση αλγορίθμων για δίκαιη κατανομή αγαθών (**EFX – Envy-Free up to any good**) σε στιγμιότυπα όπου τα αγαθά αναπαρίστανται ως **ακμές ενός γράφου** και οι πράκτορες (agents) ως **κόμβοι**. Κάθε πράκτορας μπορεί να αποτιμήσει μόνο τα αγαθά (ακμές) που είναι προσκείμενα σε αυτόν, δηλαδή που τον έχουν ως ένα από τα δύο άκρα τους.

Το project περιλαμβάνει τόσο τον πυρήνα του αλγορίθμου (command-line/library) όσο και ένα γραφικό περιβάλλον (GUI) σε Tkinter για εισαγωγή δεδομένων, εκτέλεση και οπτικοποίηση της κατανομής πάνω στον γράφο.

📄 Η πλήρης θεωρητική ανάλυση και τεκμηρίωση του προβλήματος βρίσκεται στη διπλωματική εργασία: [`thesis/efxAllocationOnGraphThesis.pdf`](thesis/efxAllocationOnGraphThesis.pdf).

## Τι είναι το EFX

Σε προβλήματα δίκαιης κατανομής αγαθών, μια κατανομή είναι **EFX** (Envy-Free up to any good) αν κανένας πράκτορας δεν ζηλεύει έναν άλλον, αφού αφαιρεθεί (νοητά) *οποιοδήποτε* αγαθό από το πακέτο του άλλου. Είναι μια από τις ισχυρότερες γνωστές έννοιες δικαιοσύνης στη βιβλιογραφία fair division.

Εδώ το πρόβλημα εξειδικεύεται στην περίπτωση όπου τα αγαθά είναι ακμές ενός γράφου: κάθε αγαθό "ανήκει" σε ακριβώς δύο πιθανούς αποδέκτες (τα άκρα της ακμής), και μόνο αυτοί οι δύο έχουν (μη μηδενική) αποτίμηση για αυτό.

## Δομή αλγορίθμου

Η κεντρική ροή (`run\_allocation` στο `allocationEFX.py`) εκτελείται σε τρεις φάσεις:

1. **Greedy Allocation** (`greedy\_allocation`) — Αρχική απόδοση: κάθε πράκτορας παίρνει την καλύτερη διαθέσιμη γειτονική του ακμή, με προτεραιότητα στον "απέναντι" κόμβο της ακμής που μόλις ανατέθηκε.
2. **Reduce Envy** (`reduce\_envy`) — Για πράκτορες που ζηλεύονται από άλλους, γίνεται προσπάθεια αντικατάστασης του πακέτου τους με αδιάθετες γειτονικές ακμές, όσο αυτό βελτιώνει την αξία τους.
3. **Allocate Remaining Goods** (`allocate\_remaining\_goods`) — Οι ακμές που παραμένουν αδιάθετες δίνονται σε μη ζηλευτούς πράκτορες· αν και τα δύο άκρα είναι ζηλευτά, χρησιμοποιείται η έννοια του **safe set** (`get\_safe\_set`) για να επιλεγεί με ασφάλεια ο αποδέκτης.

Στο τέλος γίνεται έλεγχος **EFX** (`is\_efx`) πάνω στην τελική κατανομή και υπολογίζονται στατιστικά/μετρικές απόδοσης.

## Χρήση

### Εκτέλεση του GUI

```bash
python GUI.py
```

Στο παράθυρο που ανοίγει μπορείτε να:

* επιλέξετε τρόπο εισαγωγής δεδομένων,
* ενεργοποιήσετε αναλυτικά logs κάθε βήματος του αλγορίθμου,
* εμφανίσετε τον γράφο της τελικής κατανομής (με χρωματική επισήμανση π.χ. ζηλευτών πρακτόρων),
* πατήσετε **Run Allocation** για εκτέλεση και εμφάνιση μετρικών.

### Τρόποι εισαγωγής δεδομένων

Το πρόγραμμα υποστηρίζει τρεις τρόπους εισαγωγής (βλ. `inputMethods.py`):

1. **Χειροκίνητη εισαγωγή ακμών (Text)** — Κάθε γραμμή έχει τη μορφή:

```
   A,B:valA,valB
   ```

   όπου `A,B` είναι τα δύο άκρα (agents) της ακμής (του αγαθού), και `valA,valB` οι αντίστοιχες αποτιμήσεις των A και B για αυτό το αγαθό. Παράδειγμα:

```
   A,B:10,5
   B,C:7,7
   A,C:3,9
   ```

   Το εργαλείο αποτρέπει την εισαγωγή διπλών ακμών ή ακμών που θα δημιουργούσαν multigraph.

2. **Εισαγωγή από αρχείο (File)** — Ίδια μορφή γραμμών όπως παραπάνω, μέσα σε ένα `.txt` αρχείο, φορτωμένο μέσω `get\_input\_from\_file`.
3. **Οδηγός βήμα-βήμα (Wizard)** — Εισαγωγή πρακτόρων, αριθμού αγαθών και αποτιμήσεων μέσα από διαδοχικά παράθυρα διαλόγου.

### Χρήση ως βιβλιοθήκη (χωρίς GUI)

```python
from inputMethods import get\_input\_from\_file
from allocationEFX import run\_allocation

agents, goods, valuations = get\_input\_from\_file("example.txt")
final\_alloc, report\_text, greedy\_alloc, envy\_reduced\_alloc = run\_allocation(
    agents, goods, valuations, show\_details=True
)

print(report\_text)
```

## Μετρικές εξόδου

Μετά την εκτέλεση, το `run\_allocation` επιστρέφει (και τυπώνει) μεταξύ άλλων:

* Χρόνο εκτέλεσης
* Ποσοστό πρακτόρων χωρίς κανένα αγαθό στην τελική κατανομή
* Ποσοστό/πλήθος ζηλευτών πρακτόρων ανά φάση (Greedy → Reduce Envy → Final)
* Αν η τελική κατανομή ικανοποιεί EFX
* Αριθμό/ποσοστό "unoriented" αγαθών (αγαθών που χρειάστηκαν επιλογή μέσω safe set)
* Συνολική αξία της κατανομής έναντι μιας "βέλτιστης" ανά ακμή τιμής (Σ max(vᵢ(e), vⱼ(e)))
